# IoT-GOAT-exercise
this lab teaches how to discover TCP and UDP services, inspect possible weaknesses, test a lab backdoor and evaluate lab passwords

use sudo runs Nmap with administrative privileges; -T4 increases the scan rate, so use it only in the isolated lab. The -oX option saves XML output even when the chosen filename ends in .nmap
